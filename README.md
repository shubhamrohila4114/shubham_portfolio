# Shubham Rohila — Full Stack Developer Portfolio

A cinematic, responsive portfolio built from scratch with React, Vite, Tailwind CSS, Framer Motion, and Lucide React. Resume-backed content is maintained in `src/data/portfolio.js`.

## Run locally

Requires Node.js 18+ and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. Run `npm run build` for a production build and `npm run preview` to preview it.

## Edit portfolio content

Edit the structured profile, project details, skills, experience, process, education, and certifications in `src/data/portfolio.js`. The project artwork is CSS-generated conceptual imagery and can be replaced with real screenshots when available. No project URLs, results, metrics, or project-specific technologies are asserted without resume support.

The Resume button downloads the source resume PDF from the attached resume. Contact and social destinations are defined in the profile data.

## Notes

The design uses a dark editorial palette, oversized type, layered abstract visuals, scroll-based reveals, responsive navigation, keyboard skip navigation, and reduced-motion CSS support. Google Fonts are requested remotely; system fallbacks remain available.
